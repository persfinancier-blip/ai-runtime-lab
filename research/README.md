# Research Evidence

Store durable research notes here.

Recommended filename: `YYYY-MM-DD-topic.md`.

Each note should distinguish:

- question;
- sources and retrieval date;
- factual observations;
- donor repositories/mechanisms;
- experiments performed;
- conclusions/inferences;
- confidence and unknowns;
- implementation implications.

Prefer primary sources and source code/tests. Do not use this directory as an unstructured transcript dump.
